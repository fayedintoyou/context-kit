# Working with agents

This hub holds the user's stated working preferences and reusable methods. It
should evolve from explicit direction and evidence from actual tasks.

Read [preferences.md](preferences.md) for how to approach work. For substantial
plans or deliverables benefiting from another perspective, read the
[independent-review skill](../../skills/independent-review/SKILL.md).

When refining a skill, retain a realistic task and the observed result so future
changes can be evaluated. Check actual artifacts and behavior, not just an
agent's claim that it followed instructions.

Capture a new recurring method here when it proves useful. Keep task-specific
details with the relevant project rather than turning each correction into a
universal preference.
